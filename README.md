# Plant Recognition CNN (Video Support)

Система распознавания видов растений на базе свёрточных нейронных сетей (CNN). 
Модель обучается на изображениях и способна классифицировать растения в видеопотоке в реальном времени.

## Датасет
В качестве базового используется **PlantVillage Dataset**.
- **Описание:** 54,303 изображения листьев 14 видов культурных растений в 38 категориях (здоровые/больные).
- **Ссылка:** [Kaggle - PlantVillage Dataset](https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset/data)
