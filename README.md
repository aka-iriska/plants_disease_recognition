# Plant Disease Recognition CNN (Video Support)

Система распознавания видов растений на базе свёрточных нейронных сетей (CNN). 
Модель обучается на изображениях и способна классифицировать растения в видеопотоке в реальном времени.

---

## Датасет
В качестве базового используется **PlantVillage Dataset**.
- **Описание:** 54,303 изображения листьев 14 видов культурных растений в 38 категориях (здоровые/больные).
- **Ссылка:** [Kaggle - PlantVillage Dataset](https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset/data)

---

## Get Started (API)

### Способ 1: С помощью Docker (Рекомендуемый)
Убедитесь, что у вас установлен Docker и Docker Compose.
```bash
# Сборка и запуск контейнера
docker-compose up --build
```
API будет доступно по адресу: `http://localhost:8000`

### Способ 2: Локально (через uv)
Проект использует менеджер пакетов `uv`.
```bash
uv sync --no-dev
uv run uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```


## 📊 Рекомендуемые графики и визуализации для защиты/резюме

Чтобы показать глубокое понимание работы модели, рекомендуется добавить следующие визуализации в ваш ноутбук или отчет:

1. **Метрика IoU (Intersection over Union) и Bounding Boxes**
   - **Зачем:** Показывает, насколько точно модель локализует растение/лист на фото. 
   - **Визуализация:** Выведите оригинальную картинку, где зеленым цветом нарисован *Ground Truth* (идеальный квадрат от разметчика), а красным — *Prediction* (то, что предсказала модель). Добавьте сверху значение IoU (например, `IoU = 0.85`).
2. **Тепловые карты (Grad-CAM / Saliency Maps)**
   - **Зачем:** Объясняет "куда смотрит" модель при принятии решения. Это безумно круто смотрится в резюме (Explainable AI).
   - **Визуализация:** Наложение красно-желтой тепловой карты на исходное фото листа. Показывает, что модель смотрит на пятна болезни, а не на фон.
3. **Confusion Matrix (Матрица ошибок)**
   - **Зачем:** Показывает, какие классы растений модель путает чаще всего (например, "Томат здоровый" vs "Томат больной").
4. **Кривые обучения (Loss & Accuracy)**
   - Обязательные графики Train vs Validation. Обязательно добавьте сглаживание (smoothing) на графики TensorBoard/Matplotlib, чтобы они выглядели эстетично.
5. **PR-кривые (Precision-Recall)**
   - Особенно полезно, если классы несбалансированы (например, больных растений меньше, чем здоровых).
